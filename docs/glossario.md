# Glossário

Entidades de domínio usam nomes em português (a linguagem da USP). Código técnico fica em inglês.

| Termo                                 | Significado                                                              |
| ------------------------------------- | ------------------------------------------------------------------------ |
| `curso`                               | Curso de graduação (ex.: Sistemas de Informação)                         |
| `habilitacao`                         | Variação do curso (ex.: diurno ou noturno), quando existir               |
| `curriculo`                           | Versão da grade de um curso, vinculada ao ano de ingresso                |
| `disciplina`                          | Matéria, identificada pela sigla (ex.: `ACH2036`)                        |
| `requisito`                           | Relação entre disciplinas. Tipos: `forte`, `fraco`, `indicacao_conjunto` |
| `turma`                               | Oferecimento de uma disciplina num semestre, com horários e docente      |
| `docente`                             | Professor                                                                |
| `ciclo basico`                        | Disciplinas comuns a todos os cursos da EACH (siglas ACH0xxx)            |
| `credito aula` / `credito trabalho`   | Unidades de carga horária da USP                                         |
| `optativa eletiva` / `optativa livre` | Blocos de optativas com mínimo de créditos                               |
| `AEX`                                 | Atividade extensionista curricular                                       |
| `curador`                             | Aluno responsável por revisar o conteúdo da wiki de um curso             |
| `revisao`                             | Uma versão sugerida de uma página da wiki, que passa por aprovação       |
